# MVP 범위

← [로드맵으로](../../ROADMAP.md)

**MVP = 혼자 쓰는 노션.**

데이터베이스도, 검색도 없습니다. 페이지를 만들고 · 쓰고 · 저장되고 · 다시 찾아 여는 것까지입니다.

MVP는 두 단계로 나옵니다.

| 단계 | 시점 | 상태 |
|---|---|---|
| **화면 MVP** | F3 종료 (3주) | 흐름이 전부 돌아갑니다. 데이터는 브라우저 안(localStorage) |
| **배포 MVP** | F4 종료 (4주) | 같은 흐름이 실서버에 저장됩니다. `v0.1.0` |

로그인은 MVP에 없습니다. [F5](sprint-5.md)입니다.

---

## 핵심 사용자 흐름

MVP가 끝나면 이 흐름이 처음부터 끝까지 끊기지 않고 돌아가야 합니다.

```
워크스페이스 진입
  → 페이지 생성
    → 페이지 편집 (제목 + 본문)
      → 블록 추가·수정
        → 자동 저장
          → 페이지 목록에서 다시 찾기
            → 기존 페이지 수정
```

각 단계를 어느 스프린트가 담당하는지:

| 흐름 | 담당 |
|---|---|
| 화면 재료 (로딩·에러·빈 화면·메뉴·트리 행) | F1 |
| 진입 · 목록 · 생성 · 열기 · 삭제 · 제목 편집 | F2 |
| 본문 · 블록 추가·수정 · 자동 저장 | F3 |
| 실서버 저장 · 충돌 처리 | F4 |

---

## 넣는 것

- 사이드바 페이지 트리
- 페이지 생성 / 열기 / 제목 수정 / 삭제(휴지통으로 이동)
- 블록 8종 — 문단, 제목1·2·3, 불릿, 번호 목록, 체크박스, 코드, 인용, 구분선
- 슬래시 메뉴 · 마크다운 단축 입력 · 포맷 툴바
- 자동 저장 + 저장 상태 표시
- URL이 페이지를 가리킴 (`/p/:pageId`) — 새로고침·뒤로가기 정상 동작
- 로딩 / 에러 / 빈 화면
- 다크 모드

## MVP 판정 기준

F3이 끝났을 때 이게 되면 화면 MVP입니다. F4에서 같은 항목을 실서버로 한 번 더 확인합니다.

1. 브라우저를 처음 열면 "페이지가 아직 없어요" 화면이 뜬다
2. 버튼 하나로 첫 페이지가 만들어진다
3. 제목을 쓰고, 본문에 여러 종류의 블록을 넣는다
4. 아무것도 안 눌러도 1초 뒤 "저장됨"으로 바뀐다
5. 새로고침해도 그대로 있다
6. 사이드바 목록에서 다른 페이지를 열고 다시 돌아온다
7. 위 전부를 **키보드만으로** 할 수 있다

F4에서 하나가 더 붙습니다.

8. 다른 브라우저에서 열어도 같은 문서가 보인다
