## 할 일

### 1. 자동 저장 (`features/editor/useAutosave.ts`)

언제 저장할지:

| 시점 | 동작 |
|---|---|
| 타이핑이 멈추고 800ms | 저장 |
| 계속 타이핑해도 5초마다 | 강제 저장 |
| 포커스가 빠지거나 창을 닫을 때 | 즉시 저장 |

- [ ] 저장이 진행 중일 때 새 저장 요청이 오면, 앞의 것을 취소하고 **마지막 것만** 보냅니다
- [ ] 저장 중에도 타이핑은 막지 않습니다

### 2. 충돌 처리

- [ ] `updatePage(id, patch, { baseVersion })` — 서버 `version`과 다르면 `ApiError(409, 'version_conflict')`
- [ ] 충돌 다이얼로그 — `내 것으로 덮어쓰기` / `서버 것 불러오기` 두 갈래

### 3. 저장 상태 표시

- [ ] `components/SaveStatus.tsx` — 상단바 액션 자리
- [ ] `aria-live="polite"`로 상태 변화를 읽어줍니다
- [ ] 문구는 사과하지 않습니다 (DESIGN.md §8)

  | 상태 | 문구 |
  |---|---|
  | 저장 중 | 저장 중 |
  | 완료 | 저장됨 |
  | 실패 | 저장 실패 · 다시 시도 |

### 4. 실패 처리

- [ ] `useSavePage` — 화면부터 바꾸고, 실패하면 되돌립니다
- [ ] 재시도 3번, 간격을 점점 늘립니다
- [ ] `useUnsavedGuard` — 저장 안 된 상태에서 페이지를 벗어나려 하면 경고

### 5. 품질 점검

- [ ] Playwright 도입 + **핵심 흐름 E2E 1개**

  ```
  진입 → 페이지 생성 → 제목 입력 → 블록 3개 작성
       → "저장됨" 확인 → 새로고침 → 내용 유지 확인
       → 목록에서 다시 열기
  ```

- [ ] 성능
  - 첫 화면 번들 300KB(gzip) 이하
  - 5000자 문서에서 입력이 밀리지 않음
  - mock 지연을 3초로 올려도 타이핑이 안 끊김
- [ ] 접근성
  - 키보드만으로 전체 흐름 완주
  - axe 검사에서 serious 이상 0건

### 6. 마무리

- [ ] README 갱신
- [ ] `v0.1.0` 태그
