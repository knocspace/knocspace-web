## 목표

페이지 mock을 걷어내고 실제 API에 붙입니다.

**성공 기준은 하나입니다: `src/components/`와 `src/features/`를 한 줄도 안 고치는 것.**
이게 안 되면 F1~F3의 경계 설계가 실패한 것이고, 그 사실을 여기서 알아내는 게 이 스프린트의 절반입니다.

인증은 아직 없습니다. 백엔드가 개발용으로 열어둔 워크스페이스에 붙습니다. 로그인은 [F5](sprint-5.md)입니다.

## 만드는 것

- `api/client.ts` 안쪽을 `fetch`로 교체
- mock ↔ 실서버 전환 스위치
- 응답 런타임 검증
- 저장 충돌(409) 처리 — F3에서 미뤄둔 것
- 실전 에러 처리 — 네트워크 끊김, 5xx, 재시도
- E2E 1개

## 할 일

### 0. 계약 대조 (2시간) ★ 여기서 어긋난 걸 다 찾아냅니다

- [ ] `src/types/api.ts`와 백엔드의 실제 응답을 필드 단위로 대조 ([확인 목록](backend-sync.md#f4-시작-전-확인할-것))
- [ ] 어긋난 곳은 **타입을 고치지 말고 백엔드와 합의해서 한쪽을 맞춥니다.** 프론트에서 변환 함수로 덮으면 그 함수가 영원히 남습니다
- [ ] 합의 결과를 `types/api.ts`에 반영하고 백엔드에도 공유

### 1. client 교체 (3시간)

- [ ] `api/client.ts` 안쪽을 `fetch`로 — baseURL, 공통 헤더, 상태 코드 → `ApiError` 변환
- [ ] `.env`로 mock / 실서버 전환. **당분간 둘 다 유지합니다** (백엔드가 내려가도 개발이 멈추지 않게)

  ```
  VITE_API_MODE=mock | server
  VITE_API_BASE_URL=
  ```

- [ ] `api/pages.ts`를 실제 엔드포인트에 연결
- [ ] `api/seed.ts` 제거 — 이제 서버가 데이터를 갖습니다

### 2. 응답 검증 (2시간)

```bash
npm i zod
```

- [ ] `api/schemas.ts` — `Page` / `PageSummary` 응답 스키마
- [ ] `client.ts`에서 파싱 실패를 `ApiError('unknown')`으로 바꾸고 개발 모드에서는 콘솔에 남깁니다

명세 불일치를 조용히 넘기지 않으려는 것입니다. 잘못된 필드가 화면 깊은 곳에서 `undefined`로 터지면 원인을 찾기 어렵습니다.

### 3. 저장 충돌 (3시간)

F3에서 미뤄둔 부분입니다.

- [ ] `updatePage(id, patch, { baseVersion })` — 서버 `version`과 다르면 `ApiError(409, 'version_conflict')`
- [ ] 충돌 다이얼로그 (F1의 `Dialog`) — `내 것으로 덮어쓰기` / `서버 것 불러오기` 두 갈래
- [ ] 덮어쓰기를 고르면 최신 `version`을 받아 다시 저장합니다

### 4. 실전 에러 처리 (2시간)

- [ ] 저장 재시도 3번, 간격을 점점 늘립니다. 4xx는 재시도하지 않습니다
- [ ] 네트워크가 끊기면 저장 상태를 `저장 실패 · 다시 시도`로 두고, 복구되면 자동으로 다시 보냅니다
- [ ] 5xx는 토스트로 알리고 화면을 비우지 않습니다

### 5. E2E와 점검 (3시간)

- [ ] Playwright 도입 + **핵심 흐름 E2E 1개** (실서버 대상)

  ```
  진입 → 페이지 생성 → 제목 입력 → 블록 3개 작성
       → "저장됨" 확인 → 새로고침 → 내용 유지 확인
       → 목록에서 다시 열기
  ```

- [ ] F3 에서 넘어온 둘 — **에디터 위에 뜨는 것**은 브라우저가 있는 여기서 처음 검사됩니다
      ([테스트 정책](architecture.md#테스트))

  - 슬래시 메뉴로 제목 블록 삽입 — `/` → 목록에서 고르기 → 블록이 바뀐다
  - 마크다운 단축 입력 (`# `, `- `, `1. `, `> `)

- [ ] 성능 — 문서 열기 1초 이내, 5000자 문서에서 입력이 밀리지 않음
- [ ] 접근성 — 키보드만으로 전체 흐름 완주, axe 검사에서 serious 이상 0건
- [ ] README 갱신, `v0.1.0` 태그

## 완료 조건

- [ ] `src/components/`와 `src/features/`의 변경 줄 수 **0**
- [ ] `VITE_API_MODE`를 바꾸면 mock ↔ 실서버가 즉시 전환된다
- [ ] 다른 브라우저에서 열어도 같은 문서가 보인다
- [ ] 두 탭에서 같은 페이지를 고치면 나중 저장이 충돌을 감지하고 선택지를 준다
- [ ] 네트워크를 끊었다 붙이면 저장이 스스로 복구된다
- [ ] 응답에 없는 필드가 오면 조용히 넘어가지 않고 에러로 잡힌다
- [ ] E2E 1개가 로컬에서 흔들림 없이 통과한다

[공통 완료 조건](conventions.md)도 함께 확인합니다.
