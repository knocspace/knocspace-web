## 목표

문서에 **주인을 붙입니다.** 로그인하고, 자기 워크스페이스를 보고, 남에게 문서를 공유합니다.

F4에서 세운 원칙은 그대로입니다 — 화면 컴포넌트는 서버를 모릅니다. 이번에 새로 만드는 화면은 로그인과 공유뿐입니다.

## 만드는 것

- 로그인 / 로그아웃, 토큰 갱신, 401 처리
- 라우트 가드
- 내 정보 — 이름, 아바타, `color`
- 워크스페이스 멤버, 문서 공유, 권한(보기·편집)
- 읽기 전용 모드

## 할 일

### 0. 인증 방식 확정 (1시간)

**B4 설계와 함께 정합니다.** 코드를 쓰기 전에 결정합니다.

| 항목 | 선택지 |
|---|---|
| 토큰을 어디에 두나 | httpOnly 쿠키 / 메모리 + refresh 쿠키 |
| 갱신 시점 | 401을 받고 나서 / 만료 전에 미리 |
| 로그아웃 | 서버 세션 무효화 여부 |
| CORS·쿠키 | 도메인이 다르면 `SameSite` 설정 |

### 1. 타입과 api (2시간 30분)

- [ ] `types/api.ts`에 추가 — `Session` / `Workspace` / `Member` / `Role` / `ShareTarget`
- [ ] `api/auth.ts` — `login` / `logout` / `refresh` / `getMe`
- [ ] `api/workspaces.ts` — `listWorkspaces` / `listMembers` / `invite` / `changeRole`
- [ ] `api/pages.ts`에 `getPageShares` / `sharePage` / `unsharePage`

### 2. 인증 흐름 (3시간)

- [ ] `client.ts`에 인증 헤더와 401 갱신 — 갱신 중 들어온 요청은 큐에 넣고, 갱신에 실패하면 전부 실패시키고 로그인으로
- [ ] `features/auth/useSession.ts` — 현재 사용자. 한 번만 부르고 캐시합니다
- [ ] `routes/LoginRoute.tsx`
- [ ] `routes/RequireAuth.tsx` — 라우트 가드. 로그인 후 원래 가려던 URL로 돌려보냅니다
- [ ] 로그아웃 시 Query 캐시 전체 비우기 — **안 비우면 다음 사용자에게 앞 사용자 문서가 잠깐 보입니다**

### 3. 권한 (3시간 30분)

- [ ] `features/auth/usePagePermission.ts` — 이 페이지에서 내가 할 수 있는 것
- [ ] 읽기 전용 모드 — 에디터 `editable=false`, 제목 편집 잠금, 트리 액션 버튼 숨김
- [ ] 403은 `ErrorState`로 — "이 문서를 볼 권한이 없어요"
- [ ] 권한이 없는 동작은 버튼을 **비활성이 아니라 숨깁니다** (DESIGN.md §6)

### 4. 사용자가 보이는 곳 (2시간 30분)

- [ ] `components/Avatar.tsx` — 이미지 없으면 이름 첫 글자 + `User.color`
- [ ] 상단바에 내 아바타 + 메뉴 (F1의 `Menu`)
- [ ] 문서 하단 또는 상단바에 `마지막 수정: {이름} · {시각}` — `updatedBy`를 이제 실제로 씁니다
- [ ] `features/share/ShareDialog.tsx` — 멤버 검색, 권한 선택, 현재 공유 목록 (F1의 `Dialog`)

### 5. 테스트 (2시간 30분)

유닛 — `document` 없이 도는 것만:

- [ ] 401 → 갱신 성공 → 원래 요청 재시도
- [ ] 401 → 갱신 실패 → 토큰 폐기 · `queryClient` 캐시 비워짐

E2E:

- [ ] 읽기 권한만 있으면 에디터가 편집을 막는다
- [ ] 로그인 → 문서 생성 → 로그아웃 → 다시 로그인 → 문서가 그대로 있음

"로그인 화면으로 보낸다" 와 "편집을 막는다" 는 화면에 뜨는 것이라 E2E 쪽입니다
([테스트 정책](architecture.md#테스트)).

## 완료 조건

- [ ] 로그인하지 않으면 어떤 문서 URL로도 들어갈 수 없다
- [ ] 401 → 자동 갱신 → 실패하면 로그인으로
- [ ] 로그아웃 후 다른 계정으로 로그인하면 앞 계정 데이터가 한 프레임도 안 보인다
- [ ] 편집 권한이 없으면 에디터가 읽기 전용으로 뜨고, 편집 버튼이 화면에 없다
- [ ] 문서에 마지막 수정자가 실제 사용자 이름으로 표시된다
- [ ] 새 화면(로그인·공유) 말고 기존 화면 컴포넌트의 변경이 최소로 유지된다

[공통 완료 조건](conventions.md)도 함께 확인합니다.
